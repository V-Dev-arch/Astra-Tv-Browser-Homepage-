📺 About Astra

ASTRA is a futuristic browser homepage interface specially designed for Smart TVs, Android TV systems, Fire TV devices and remote-based navigation environments.

Unlike traditional browser homepages, Astra focuses on:

- television-friendly layouts
- focus-based navigation
- cinematic visuals
- large UI elements
- smooth directional movement
- lightweight rendering
- couch-friendly browsing experience

Astra transforms ordinary TV browsers into a modern dashboard-style interface.

🔥 Smart Navigation Toggle System

🆕 Remote Navigation ON/OFF Feature

One of Astra’s most advanced features is the ability to enable or disable the custom remote navigation system.

---

❓ Why This Exists

Some TV browsers already include native remote navigation systems.

Examples include:

- TV Bro
- Smart TV browsers
- Browser engines with built-in focus handling

Running both systems together may cause:

- double focus movement
- navigation conflicts
- broken focus detection
- glitchy movement behavior

---

✅ Astra Solution

Astra includes a dedicated:

🎮 Remote Navigation ON/OFF Toggle

Users can:

- disable Astra navigation engine
- use browser-native navigation
- prevent navigation conflicts
- switch systems instantly

This creates much better compatibility with TV browsers.
